# 🚀 Social Media Dashboard - MERN Stack

A real-time social media management tool featuring a **Glassmorphism UI**. This project focuses on high-concurrency features like WebSockets for instant interactions and MongoDB Atlas for cloud data storage.

## ✨ Key Features
* **Real-time Feed** 📱: Posts appear instantly on all connected clients using Socket.io.
* **Instant Likes** ❤️: Like counts update in real-time without refreshing the page.
* **Analytics Overview** 📊: Track key metrics like followers, engagement, and reach.
* **Glassmorphism UI** 🌌: Futuristic frosted-glass interface built with Tailwind CSS.
* **Cloud Database** ☁️: Powered by MongoDB Atlas for persistent storage.

## 🛠️ Tech Stack
* **Frontend**: React.js (CDN), Tailwind CSS
* **Backend**: Node.js, Express.js
* **Real-time**: Socket.io
* **Database**: MongoDB Atlas

## 📂 Project Structure
* `server.js`: Node/Express logic with Socket.io integration.
* `index.html`: Ultra-immersive Glassdoor Frontend.

## 📈 Quick Setup

1. **Clone the repository** 📁:
   ```bash
   git clone https://github.com/SonamSingh510/social-media-dashboard.git
   ```

2. **Install Dependencies** 🛠️:
   ```bash
   npm install express mongoose socket.io cors
   ```

3. **Configure Database** 🔑:
   Open `server.js` and replace the `MONGO_URI` variable with your MongoDB Atlas connection string.

4. **Run the Server** ▶️:
   ```bash
   node server.js
   ```

5. **Launch Frontend** 🌐:
   Open `index.html` in your browser.
